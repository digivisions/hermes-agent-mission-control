## RealXR

Digital Visions' own premium, character-driven **XR experience product**. It is
sold through video: reels and scripted CGI/VFX scenes, mostly limbo-space
product shots of the XR glasses.

Working directory: `/Users/annguyen/RealXR_Character` (this was `location: null`
in the project registry until Spec I; now backfilled).

> **No code repository, no `CLAUDE.md`, no Claude Code project memory.** This
> note plus the asset sheets are the entire recorded context — the content was

### The canonical character — the one rule

There is **ONE** reference character and every visual must use her: a
sharp-featured Vietnamese woman in the Veronica Ngo mould, gunmetal coat with a
mandarin collar. **Never generate a new face.**

`Scene_Cyberpunk_City.png` and `RealXR_Prop_Cyberpunk.png` carry the cyberpunk
direction. The default product treatment is **limbo space** — a clean,
contextless void — with cyberpunk as a scripted contrast, not the everyday look.
